# 💼 Developer Portfolio

A modern, responsive, and professional developer portfolio built with **React.js** and **Tailwind CSS**. This project showcases my skills, projects, education, certifications, and contact information in a clean and user-friendly interface.

## ✨ Features

* 🌙 Dark & Light Mode
* 📱 Fully Responsive Design
* ⚡ Built with React.js & Tailwind CSS
* 🎨 Clean and Modern UI
* 🎭 Smooth Animations with Framer Motion
* 📄 Resume Download
* 📂 Dynamic Project Showcase
* 🛠️ Skills & Technology Stack
* 🎓 Education & Certifications
* 📧 Contact Form (EmailJS)
* 🔝 Scroll to Top Button
* 🚀 Optimized Performance
